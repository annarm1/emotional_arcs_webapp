# Веб-ресурс для анализа эмоциональной динамики текстов на русском языке

Веб-ресурс для анализа эмоциональной динамики художественных текстов. Приложение позволяет загружать тексты, извлекать прямую речь персонажей, рассчитывать эмоциональные показатели и строить интерактивные графики эмоциональных арок.

Проект разработан в рамках выпускной квалификационной работы.

---

## Возможности

* Загрузка текстов в форматах `.txt`, `.xml`
* Автоматическое извлечение прямой речи персонажей из текстов с TEI-разметкой
* Анализ эмоциональной окраски текста и реплик персонажей
* Построение эмоциональных арок произведения и отдельных персонажей
* Выбор подхода сентимент-анализа
* Настройка параметров анализа
* Интерактивный график

---

## Доступ
Ресурс доступен по ссылке https://emotional-arcs.streamlit.app

## Использование

1. Загрузите текст произведения;
2. Выберите модель сентимент-анализа;
3. Выберите параметры анализа:
   * минимальную и максимальную длину сегментов;
   * контекстное окно;
4. Нажмите **«Сегментировать текст и определить тональность»**;
5. Настройте сглаживание графика;
6. Изучите результаты.
